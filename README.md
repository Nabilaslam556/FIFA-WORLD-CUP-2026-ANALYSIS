# ⚽ FIFA World Cup 2026 Player Performance Analysis

## 📌 Project Overview

This project presents a comprehensive **Exploratory Data Analysis (EDA)** of a FIFA World Cup 2026 Player Performance dataset.

The objective is to analyze player, team, and match statistics to identify performance patterns, trends, relationships, and outliers. The analysis transforms raw football statistics into meaningful insights that can help understand player contributions and overall tournament performance.

---

## 🎯 Objectives

* Understand the structure and quality of the dataset.
* Analyze player demographics and physical characteristics.
* Evaluate offensive and defensive player performance.
* Compare team and nationality performance.
* Identify top-performing players using multiple performance metrics.
* Study relationships between player ratings and match statistics.
* Detect patterns, trends, and outliers using data visualization.
* Generate meaningful insights from player and tournament statistics.
